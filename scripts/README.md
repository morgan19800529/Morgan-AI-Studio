# scripts · 每日短视频内容库

Morgan AI Studio 的每日产出归档。每天一条 **20 秒英文心灵鸡汤短视频脚本**（含拍摄卡 + 中文对照）。

- 一天一个文件：`YYYY-MM-DD.md`。
- 由每日定时任务 `daily-inspo-short-en-th` 生成（每天早上约 9:00）。

## 用法
1. 拿当天脚本直接开拍 → 发布。
2. 把表现填进 `database/复盘模板.csv`。
3. 打开复盘看板看数据：https://morgan19800529.github.io/ai-creator-os/dashboard.html

攒起来，就是一份可复用、可回看的文案资产。
