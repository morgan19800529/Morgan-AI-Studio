# prompts · Prompt Library

模块化、可复用的 Prompt 库。每个 Prompt 独立成文件，含：用途 / 输入 / 输出 / 示例 / 版本。

## 分类（规划）
Marketing · Video · YouTube · TikTok · Xiaohongshu · 公众号 · 直播 · AI Agent · Coding · English · Thai · Health · Business

## 约定
- 命名：`<分类>/<用途>.md`，例如 `直播/留人开场.md`
- 每个 Prompt 顶部写 front-matter：`title / category / version / inputs / outputs`
- 复用优先：能参数化就不写死；能组合就不重复
