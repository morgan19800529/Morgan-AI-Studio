# prompts/分发 · 内容分发 Prompt 分类

服务 V3「AI 内容分发」：一次直播/长内容 → 自动切成短视频、图文、多平台内容。让一次创作产出十条。

| Prompt | 用途 |
| --- | --- |
| [短视频切片.md](短视频切片.md) | 直播稿/长文 → 3~5 条独立短视频脚本（含钩子、字幕、时长） |
| [图文改写.md](图文改写.md) | 长内容 → 小红书图文 / 公众号文章 |
| [多平台适配.md](多平台适配.md) | 同一条内容 → 抖音/视频号/小红书/YouTube 语气与格式适配 |

## 约定
- 每个 Prompt 顶部带 front-matter：title / category / version / inputs / outputs。
- 输入统一是"一段已有内容"（直播稿、口播稿、文章都行）。
- Reusable First：切片/改写/适配三步可单独用，也可串起来。
