# Vision · 愿景

## 使命
帮助普通创作者建立完整的 AI 内容生产系统 —— 不是做一个工具，而是打造 **AI Creator OS**。

## 闭环
```
灵感 → 市场分析 → 选题 → 脚本 → 提词 → 直播 → 剪辑 → 发布 → 复盘 → AI优化 → 持续成长
```
单个工具都有强对手；真正稀缺的是**数据在环里的沉淀**：复盘回流到选题，选题带着经验进入脚本。闭环才是护城河。

## 设计原则
- **先解决真痛点**：卡点不是"不会提词"，是"不知道讲什么、怎么坚持、什么内容有效"。
- **隐私优先**：脚本 / 数据默认只存本机。
- **务实迭代**：每个模块先自己用真实内容跑通，验证有人用，再往下做。

## 北极星
让一个 47 岁的普通人，也能持续表达、建立品牌 —— 并把这条路径产品化，复制给 100 万创作者。
