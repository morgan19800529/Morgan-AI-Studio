# Architecture · 系统架构

## 两层结构
- **HQ 仓库（本仓库）**：文档 / Prompt / Workflow / 知识 / 商业 / 看板中枢。不放大型产品代码。
- **产品仓库（独立）**：各产品自治，前端优先 PWA。示例：`iphone-teleprompter`。

## 数据闭环（护城河）
```
发布 → 采集表现数据 → 复盘（database/ + dashboard/）
      → 回流选题库 → 进入脚本 Prompt → 下一次创作更准
```

## 技术选型（初版，可演进）
- 前端：PWA（移动优先、防息屏、本地存储）
- AI：可替换的服务端代理封装（模型可换、密钥不落库）
- 存储：默认浏览器本机；跨设备再评估轻后端
- 自动化：重复任务脚本化，Prompt 模块化复用

## 演进原则
Scalable First + Reusable First：先跑通最小闭环，接口稳定后再抽象，不预造空壳。
